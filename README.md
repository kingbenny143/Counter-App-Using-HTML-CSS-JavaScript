# Counter App

A simple Counter App built using HTML, CSS, and JavaScript.

## Features

- Increase counter
- Decrease counter
- Reset counter
- Real-time DOM updates
- Clean UI design

## Technologies Used

- HTML
- CSS
- JavaScript

## Project Structure

counter-app/
│
├── index.html
├── styles.css
└── script.js

## JavaScript Concepts Used

- Variables
- Event Listeners
- DOM Manipulation
- Functions
- State Management

## How It Works

1. User clicks a button
2. JavaScript detects the event
3. Counter value updates
4. DOM updates instantly
